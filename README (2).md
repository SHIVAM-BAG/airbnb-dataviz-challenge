## Chicago vs New Orleans

### Project Overview
This project presents an interactive Power BI dashboard comparing Airbnb listings in Chicago and New Orleans. It explores listing distribution, room types, average prices, geographical locations, and the relationship between listing prices and reviews.

### Objectives
- Compare Airbnb listings across two cities.
- Analyze room-type distribution.
- Explore average listing prices and review patterns.
- Visualize listing locations geographically.
- Enable interactive analysis using dashboard filters.

### Tools & Technologies
- Power BI Desktop
- Airbnb Listings Dataset
- Data Cleaning and Transformation
- Data Visualization

### Dashboard Features

**1. City-Wise Listing Analysis**
Compares the number of listings in Chicago and New Orleans.

**2. Room-Type Analysis**
Displays the distribution of entire homes/apartments, private rooms, hotel rooms, and shared rooms.

**3. Geographic Analysis**
Maps Airbnb listings using latitude and longitude.

**4. Pricing and Reviews**
Explores the relationship between listing prices and the number of reviews.

**5. Interactive Filters**
Allows users to filter the dashboard by city and room type.

### Key Metrics
- Total listings displayed: approximately 14.061K
- Average price displayed: 551.00

*Metrics should be verified against the underlying dataset before publication.*

### Dataset
Source: [Inside Airbnb](https://insideairbnb.com/get-the-data/)

The dataset contains listing-level information, including room type, price, neighbourhood, reviews, host details, and availability.

### How to Run
1. Download this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. Use the city and room-type filters to explore the dashboard.
